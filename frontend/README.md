# Template — React · Estado e Componentes

Projeto inicial (Vite + React) para resolução dos exercícios de Estado e Componentes.

## Como usar

```bash
npm install
npm run dev
```

## Estrutura

```
src/
 ├── componentes/   # componentes reutilizáveis (ex.: StatusFuncionario, ListaSenhas, CardParticipante)
 ├── pages/         # páginas de cada exercício (ex.: PainelDisponibilidade, PainelSenhas, ListaPresenca)
 └── App.jsx        # use para testes manuais, importando e renderizando as páginas/componentes criados
```

## Antes de entregar

- Remova a pasta `node_modules` antes de compactar o projeto.
- Envie o `.zip` **exclusivamente pelo Moodle**.
- Entregas enviadas por e-mail terão a nota zerada.
